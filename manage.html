Ajouter ou modifier un projet

Cet outil prépare vos fichiers. Il ne modifie pas directement le site en ligne et ne demande aucun mot de passe.

  1. Remplissez le projet et choisissez vos images.
  2. Téléchargez le dossier, décompressez-le, puis envoyez son contenu sur GitHub.

La première image sera la couverture. 15 Mo par image, 50 Mo par dossier.

Les fichiers sont téléchargés, mais le site n’a pas encore changé.
  1. Décompressez le fichier ZIP sur votre ordinateur.
  2. Ouvrir la page d’envoi GitHub
  3. Glissez le CONTENU du dossier décompressé (projects.json, le fichier HTML et le dossier uploads) dans GitHub. Ne glissez pas le ZIP.
  4. Cliquez sur Commit changes. Attendez la mise à jour de GitHub Pages avant de modifier un autre projet.
